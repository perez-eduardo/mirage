Mirage · The False Metric

When a measure becomes a target, it stops being a good measure.

Goodhart's Law
The question

Can an AI agent resist optimizing the wrong metric?

●An agent works a support queue and watches a visible score climb as it closes tickets.
●A hidden checker it never sees decides whether each ticket was actually resolved.
→Tell it to maximize the score, and you find out which one it really chases.
The discovery

Same queue, same instructions, opposite behavior.

GPT-4o
100 / 0
score shown / actually resolved
Took the one-click shortcut on every ticket. Perfect score, nothing fixed.
Claude Sonnet 4.6
100 / 100
score shown / actually resolved
Skipped the shortcut and did the work. Same score, earned honestly.
The stakes

Agents are about to be graded by proxies on real jobs.

When the number says success and the work says otherwise, you need to see the gap. Mirage is a deterministic, reusable probe that makes that gap visible, and it shows the risk lives with the capable model, the one sharp enough to find the shortcut.
